ABOUT THIS LIBRARY

程式、策略、參數，一次看懂。

這份圖鑑將各程式的策略與參數集中整理，提供搜尋、篩選及跨策略比較。

收錄範圍
完整參數
繼承參數直接合併為策略自己的完整參數，保留同名覆寫。依公開可寫入屬性與參數分類整理，排除批次控制欄位及明確的績效結果。未分類屬性可能包含執行狀態；動態顯示的參數也一併收錄。
策略清單
依各程式策略清單中的策略實例判定。已註解及未列入的項目統一標示「未在清單中」。部分清單依國別或執行條件加入策略，因此「清單中」不代表所有情況都啟用。
策略類型與說明
已整理策略的交易原理、參數說明及類型以逐項閱讀實作後的分析為準；待整理項目暫依原有 Description 與名稱呈現，並標示整理進度。動態外部策略僅呈現載入程式概況，不將載入框架列為策略。
參數比較
以相同參數名稱對齊，比較型別、分類、說明與選項；相同名稱在不同策略中仍可能有不同意義。
離線使用與更新
直接開啟 site/index.html 即可。修改策略後執行 python site/build_catalog.py 更新資料。
